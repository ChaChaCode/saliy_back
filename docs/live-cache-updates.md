# Свежесть данных магазина после изменений в админке

Изменение в админке (новый, изменённый или удалённый товар, категория, баннер) покупатель
видит при следующем открытии или обновлении страницы. Открытые вкладки сами не
обновляются: так работают обычные магазины, и это не требуется.

## Как устроено

- **Backend не кеширует данные магазина.** Товары, категории и баннеры читаются из базы
  на каждый запрос; внутренний кеш используется только для входа в админку.
  Все ответы `/api` идут с `Cache-Control: no-store`, браузер их не хранит.
- **Магазин запрашивает API без кеша.** Общий API-клиент магазина использует
  `cache: 'no-store'`; прежние параметры `revalidate: 60` в отдельных сервисах ни на что
  не влияют.
- **Главная и каталог рендерятся на каждый запрос** (`force-dynamic`). До 3 ноября 2026 они
  собирались как ISR на 60 секунд: новый товар появлялся через минуту с лишним и только
  после того, как кто-то открывал страницу. Страницы товаров и категорий и раньше
  рендерились по запросу.
- **React Query в магазине**: `staleTime` 0, поэтому клиентские данные перечитываются при
  возврате во вкладку.
- **Админка** после любого успешного изменения перечитывает свои данные, кроме только что
  удалённого объекта.

## SSE-подписка удалена

31 октября 2026 была добавлена подписка открытых вкладок на `GET /api/storefront/changes`
(SSE): после любого изменения в админке все открытые страницы магазина перезагружали данные.
3 ноября 2026 её удалили: такой режим не нужен, держит постоянное соединение на каждую
вкладку и не работает при нескольких процессах backend без общей шины. Удалены модуль
`src/storefront-sync/`, его регистрация и исключение из gzip; подписка в `QueryProvider`
магазина убрана. Адрес `/api/storefront/changes` теперь отвечает 404.

## Исходники магазина: перенести в репозиторий

Изменения сделаны в серверной копии магазина и должны попасть в его репозиторий одним
патчем: [storefront-fresh-data.patch](./patches/storefront-fresh-data.patch) — `src/lib/api.ts`
(`no-store`), `src/providers/QueryProvider.tsx` (`staleTime` 0), `src/app/page.tsx`
и `src/app/catalog/page.tsx` (`force-dynamic`). Применяется к коммиту `d16019a`:
сначала `git apply --check`, затем `git apply`.

Патч админки — [admin-live-cache.patch](./patches/admin-live-cache.patch) (перечитывание
данных после изменений), к SSE не относится и остаётся в силе.
