# Изображения: AVIF и запасной JPEG

Все фото (товары, баннеры, отзывы, аватары) бэкенд хранит в двух копиях с общим именем:

- `<имя>-opt.avif` — основная копия, AVIF;
- `<имя>-opt.jpg` — запасная копия для браузеров без AVIF. У фото с прозрачностью запасная копия — `<имя>-opt.webp`.

Во всех полях API (`images[].url`, `desktopImageUrl`, `mobileImageUrl`, `images` отзыва, `avatarUrl`) приходит ссылка на **запасную** копию. Поэтому фронт, который ничего не знает про AVIF, продолжает работать и показывает JPEG.

## Что нужно сделать фронту, чтобы браузеры получали AVIF

1. **Правило адреса.** Если ссылка заканчивается на `-opt.jpg` или `-opt.webp` (без учёта регистра), рядом гарантированно лежит AVIF: тот же адрес, но с расширением `.avif`. Для любой другой ссылки AVIF-копии нет, и её показывают как есть. Подставлять `.avif` к ссылкам без `-opt` нельзя: такого файла нет, и картинка не загрузится.

2. **Вывод через `<picture>`.** Для ссылок с `-opt` картинка выводится элементом `<picture>`. Внутри первым идёт `<source>` с AVIF-адресом и `type="image/avif"`, затем обычный `<img>` со ссылкой из API. Браузер с поддержкой AVIF берёт первый вариант, старый (Safari на iOS 15 и старше) — `<img>`. Атрибуты `alt`, классы, `sizes`, `loading` и `fetchpriority` остаются на `<img>`.

3. **Где менять.** Все места, где фото из API выводятся через `next/image`: карточка товара (обе картинки — основная и при наведении), галерея и карусель товара, лайтбокс, баннеры главной (мобильная и десктопная версии), корзина, «Мои заказы», карусель, страница «О нас». Удобнее всего сделать один общий компонент-обёртку и заменить им `Image` в этих местах. В Next.js для этого есть `getImageProps` — он отдаёт те же атрибуты `<img>`, что и `Image`, включая стили для `fill`, поэтому вёрстка не меняется.

4. **Первый баннер.** Если для первого слайда баннера браузеру заранее подсказывается загрузка (`priority` / preload), подсказка должна вести на AVIF с `type="image/avif"`, а не на JPEG. Иначе браузер скачает обе копии.

5. **Проверка.** В Chrome во вкладке Network у картинок товаров и баннеров должен быть тип `avif`. В Safari на iOS 15 (или в эмуляторе) — `jpeg`, и фото должны показываться.

## Вес

| Где | AVIF | Запасной JPEG |
|---|---|---|
| Фото товара (до 2000 px) | 130–180 KB | 125–150 KB |
| Баннер десктоп (до 2560 px) | 210–265 KB | 150–185 KB |
| Баннер мобильный (до 1440 px) | 95–120 KB | 85–100 KB |

Подробнее о сжатии и хранении — [docs/Admin/images.md](../Admin/images.md).
