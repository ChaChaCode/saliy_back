# Выкладка Т-Банка — 31 октября 2026

По запросу владельца backend переключён на единственный способ оформления
`CARD_ONLINE` через **тестовый DEMO-терминал** Т-Банка. Реальная оплата пока не включена.

## Что выложено

- Текущие изменения src, prisma (изменение комментария enum), certs и документации.
- Исправлен `RedirectDueDate`: `YYYY-MM-DDTHH:mm:ss+00:00` вместо ISO с миллисекундами и Z.
  На DEMO-терминале запрос с прежним форматом возвращал 9999, с исправленным — успех.
- На сервере настроены тестовые реквизиты в backend `.env`, без публикации секретов.
- Backend пересобран на Linux, процесс `saliy_back` перезапущен, PM2-состояние сохранено.
- Миграции БД не запускались: новых структурных изменений нет.
- Frontend не менялся и не перезапускался: его разработчик готовит совместимый checkout.
  Во время выкладки серверный frontend ещё был на коммите `cf9ea26`, версия 0.3.4,
  со старыми способами оплаты. До его обновления оформление со старого UI несовместимо.

## Проверки

- Локально и на сервере: 2 набора, 5 тестов прошли; сборки успешны.
- Перед переключением незавершённых заказов Точки/Яндекса со статусом PENDING: 0.
- Полный `registerOrder` с новой датой, PayType, SuccessURL, FailURL и NotificationURL
  успешно создал отдельный DEMO-платёж с сервера. Это проверка Init, без заказа в БД.
- Публичные `/api/health` и `/api/orders/delivery-options?country=RU` доступны;
  последний возвращает `paymentMethods: ["CARD_ONLINE"]`.
- Webhook без подписи отклоняется HTTP 403.
- Полный цикл через checkout, обновление заказа webhook-ом и пользовательский возврат
  ещё не проверены; потребуется обновлённый frontend.
